# 侨批中的家国情怀

以「侨批」为载体的潮汕侨乡家国情怀主题数字展陈项目。项目主体为微信小程序，并配套提供同内容的 H5 网页版，便于在浏览器与社交平台分享传播。

## 项目简介

「侨批」是海外侨胞寄给国内亲属的家书与汇款凭证，2013 年被列入联合国教科文组织《世界记忆名录》。本项目依托档案馆馆藏侨批实物，通过图文、释文、注解与历史背景解读，讲述抗日战争时期潮汕侨胞的家国故事。

内容分为六个篇章，以馆藏侨批档案为主线：

| 章节 | 标题 | 主题 |
| --- | --- | --- |
| 第一章 | — | 侨批与家国情怀导览 |
| 第二章 | 革命尚未成功 · 同志仍须努力 | 吴乾祥寄张一民书（含信纸页眉「总理遗嘱」） |
| 第三章 | 斑斑血泪斑斑恨 | 新加坡华侨林忠发寄母书（潮城被炸） |
| 第四章 | 吾虽洋地 · 志在家乡 | 泰国华侨陈维忠寄母书 |
| 第五章 | 惊闻战事 · 俺乡如何 | 洪家成、金丰家书与《大公报》米荒剪报 |
| 第六章 | 国际风云 · 波及南洋 | 金丰南洋家书与太平洋战争时期侨胞处境 |
